# Data Structures and Applications – III Semester CSE

## Course
BCSPCC313 – Data Structures and Applications

## Activity
Problem Solving Using Data Structures and Algorithms

## Programming Language
C

## Topics and Programs

### 1. Stack and Queue Applications
- Infix to postfix conversion and postfix evaluation
- Circular queue with insertion, deletion and display

### 2. Trees and Tree Traversals
- Binary tree creation and preorder, inorder and postorder traversals
- Construct binary tree from inorder and preorder; count leaves and height

### 3. Threaded Binary Trees
- Inorder threaded binary tree insertion
- Inorder traversal without recursion or stack

### 4. Binary Search Trees
- BST insertion, searching, deletion and inorder display
- Count nodes, leaves, height, minimum and maximum

### 5. Graphs and Traversals
- DFS and BFS using adjacency matrix and adjacency list
- Connected components and connectivity of an undirected graph

### 6. Hashing
- Static hashing using linear probing
- Static hashing using chaining with linked lists

### 7. Leftist Trees
- Leftist tree insertion and merge
- Delete-min and priority queue implementation

## Repository Structure
Programs are organized into folders according to the seven topics.

## Objectives
- Understand and implement data structures using C.
- Practice algorithmic problem-solving.
- Analyze time and space complexity.
- Maintain source code using Git and GitHub.
